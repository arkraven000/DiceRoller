## 8. Critical Bugs Fixed

### 🐛 Bug #1: App.xaml.cs Key Management Flow (CRITICAL)

**Status:** ✅ FIXED

**Location:** `/src/DiceRoller/src/DiceRoller.App/App.xaml.cs:104-150`

**Issue:**
```csharp
// BEFORE (broken):
byte[]? encryptionKey = await keyService.RetrieveKeyAsync(keyName); // ❌ Method doesn't exist
await keyService.StoreKeyAsync(keyName, encryptionKey);            // ❌ Method doesn't exist
```

**Root Cause:**
- Called non-existent async methods on `IKeyManagementService`
- Actual interface has synchronous methods: `RetrieveProtectedKey()` and `StoreProtectedKey()`
- Forgot to protect/unprotect keys using DPAPI

**Fix Applied:**
```csharp
// AFTER (fixed):
byte[]? protectedKey = keyService.RetrieveProtectedKey(keyName);
if (protectedKey == null) {
    encryptionKey = keyService.GenerateKey();
    byte[] protectedNewKey = keyService.ProtectKey(encryptionKey);
    keyService.StoreProtectedKey(protectedNewKey, keyName);
} else {
    encryptionKey = keyService.UnprotectKey(protectedKey);
}
```

**Impact:**
- **CRITICAL** - Application couldn't initialize database before fix
- Database encryption key management completely broken
- Fix restores proper DPAPI protect/unprotect flow

### 🐛 Bug #2: ViewModel Navigation Method Mismatch (HIGH)

**Status:** ✅ FIXED

**Location:** `/src/DiceRoller/src/DiceRoller.App/ViewModels/ViewModelBase.cs:33-51`

**Issue:**
```csharp
// Base class:
public virtual void OnNavigatedTo() { }

// Derived classes (UnitLibraryViewModel, WeaponLibraryViewModel):
public override async Task OnNavigatedToAsync() // ❌ Wrong signature
{
    await LoadUnitsAsync();
}
```

**Root Cause:**
- Derived classes trying to override `OnNavigatedTo()` with `OnNavigatedToAsync()`
- Method name and signature don't match base class
- Override never actually called - derived method never executed

**Fix Applied:**
```csharp
// Base class now supports both:
public virtual void OnNavigatedTo()
{
    _ = OnNavigatedToAsync();
}

public virtual Task OnNavigatedToAsync()
{
    return Task.CompletedTask;
}

// Derived classes can now properly override:
public override async Task OnNavigatedToAsync()
{
    await LoadUnitsAsync();
}
```

**Impact:**
- **HIGH** - Navigation lifecycle methods not executing
- Data not loading when navigating to library pages
- Fix allows async initialization on navigation
